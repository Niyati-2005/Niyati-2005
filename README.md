## 🏗️ Building a Processor From Scratch

One of my long-term projects is designing a processor completely from the ground up.

The goal is not simply to have a working CPU, but to deeply understand:
- Instruction Set Architecture (ISA)
- Datapath Design
- Control Logic
- Memory Systems
- Pipeline Design
- RTL Implementation
- Verification Methodology

I'm documenting the entire journey—from learning computer architecture fundamentals to implementing a functional RISC-V processor.
